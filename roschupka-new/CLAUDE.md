# roschupka-new

Рабочая папка редизайна сайта roschupka.ru. Здесь живёт весь новый код: HTML, CSS, шаблоны. Отсюда в конечном счёте развернётся новый сайт.

Блог работает на **Эгее** (серверный PHP-движок): лента и страница поста рендерятся из одной темы. Оформление блога — это тема (CSS), а не статические HTML-страницы, которые мы пишем. Портфолио — отдельная статическая страница.

---

## Правила работы с файловой системой

- Папка `../` (то есть `roschupka.ru/`) — **рабочий сайт, не трогать**. Никаких правок, переименований, удалений.
- Из `../` можно **только читать**: смотреть стили, брать референсы CSS, изучать структуру тем Эгеи.
- Конкретные файлы для чтения:
  - `../blog/system/themes/custom theme/styles/main.css` — текущая тема блога (Literata + Open Sans)
  - `../done/css/custom.css` — стили портфолио (переменные цветов, Source Sans Pro)
  - `../main/css/custom.css` — стили главной страницы

---

## Цели редизайна

1. `roschupka.ru` открывает блог напрямую — страница-заглушка уходит.
2. Общая шапка-меню на всех страницах: Блог | Портфолио | Телеграм.
3. Единая дизайн-система: один набор CSS-токенов (цвета, шрифты, отступы).
4. Актуальное портфолио (формат TBD, контент устарел — последнее обновление дек. 2022).
5. Полная пересборка визуала — старые стили не переносим, только логику структуры.

---

## Указатели

Справочник читаем по требованию, не держим в этом файле:

- **Дизайн-токены** (шрифты, цвета, шкала, отступы) — `assets/css/tokens.css`. Единственный источник правды.
- **Спецификация вёрстки** (структура страниц, дерево файлов) — `references/spec.md`.
- **Референсы** (заполняет Артём: ссылка на сайт + что взять) — `references/refs.md`.
