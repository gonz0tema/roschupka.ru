# Спецификация вёрстки roschupka-new

Дизайн-токены (шрифты, цвета, шкала, отступы) — в `assets/css/tokens.css`. Здесь на них только ссылаемся, не дублируем.

## Структура страниц

Блог работает на **Эгее** (серверный PHP-движок): лента и страница поста рендерятся из **одной темы**, поэтому это один стиль в двух представлениях — отдельные HTML-шаблоны не пишем. Портфолио — отдельная статическая страница.

Источники стилей блога (только чтение): `../main/css/custom.css` + поверх `../blog/system/themes/custom theme/styles/main.css`.

```
Шапка (компонент, повторяется на всех страницах)
  [Артём Рощупка]          [Блог]  [Портфолио]  [Телеграм →]

─────────────────────────────────────────────────

Блог (Эгея) — одна тема, два представления

  Лента (главная = roschupka.ru)
    Шапка
    Интро (одна строка, --text-base, --color-text-secondary)
    ───
    Дата · #тег               ← --text-sm, --color-text-secondary
    Заголовок поста            ← Literata Semi Bold, --text-2xl
    Превью (2–3 строки)        ← Inter Regular, --text-base
    ───
    ... (повторяется)
    Футер

  Страница поста
    Шапка
    Дата · #тег
    H1                         ← Literata Semi Bold, --text-3xl
    ───
    Лид                        ← Literata Italic, --text-lg
    Тело поста                 ← Literata Regular, --text-base
    ← Пред. пост    След. пост →
    Футер

─────────────────────────────────────────────────

Портфолио
  Шапка
  О себе (кратко)
  Список работ / кейсов      ← формат TBD
  Контакты
  Футер
```

## Планируемая структура файлов

```
roschupka-new/
├── CLAUDE.md
├── references/
│   ├── refs.md              ← ссылки на референсы (заполняет Артём)
│   └── spec.md              ← этот файл: структура страниц и дерево файлов
├── assets/
│   ├── css/
│   │   ├── tokens.css       ← CSS-переменные (единственный источник правды)
│   │   ├── base.css         ← типографика, ссылки, reset
│   │   ├── header.css       ← стили шапки
│   │   └── blog.css         ← стиль темы блога; деплоится в тему Эгеи
│   └── partials/
│       └── header.html      ← HTML-фрагмент шапки (один источник)
└── portfolio.html           ← портфолио (статическая страница)

Блог (лента + пост) не имеет отдельных HTML-файлов здесь — его отдаёт
Эгея, а мы задаём вид одной темой (blog.css). Портфолио — статическое.

## Встраивание блога в общий сайт (Эгея)

Как блог получит общую шапку/подвал и единые стили — через **«Встраиваемую» тему** Эгеи (`embeddable`):

1. Скопировать тему `embeddable` в папке `themes`, назвать по-своему.
2. В `theme-info.php` раскомментировать строки; в `global_styles` указать путь к общему CSS сайта (относительно папки Эгеи).
3. В настройках Эгеи выбрать свою тему.
4. В `templates/layout.tmpl.php` завернуть содержимое блога в ту же шапку/подвал, что на остальных страницах.

Так блог подхватывает и наши стили, и свои внутренние. Это прямой путь к целям «общая шапка» и «единая дизайн-система».

⚠️ Инструкция от 2017 года (Эгея 2.7). Перед внедрением сверить с актуальной версией — названия тем и файлы могли измениться: <https://ilyabirman.ru/meanwhile/all/embed-aegea-2-7/>
```
