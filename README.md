# roschupka.ru

Исходники оформления личного сайта: [roschupka.ru](https://roschupka.ru)

| Раздел | Адрес | Что это |
|---|---|---|
| Блог | `/blog/` | тема для движка Эгея |
| Обо мне | `/done/` | статическая страница |
| Генератор градиентов | `/gradient-generator/` | холст и панель настроек в браузере |

## Блог работает на Эгее

[Эгея](https://blogengine.ru) — движок блогов Ильи Бирмана. Он платный, и его исходников здесь нет: в репозитории лежит только своё оформление.

Тема несамостоятельная. В `theme-info.php` стоит `based_on => plain`, то есть она надстройка над стоковой «Простой»: шаблоны, комментарии, формы и галереи достаются от неё.

Настраивается тема не селекторами, а переменными plain — их там 75: `--noteTextFontSize`, `--headingsColor`, `--linkColor` и прочие. Свои правила нужны только там, где plain задаёт значение числом и переменной для него не предусмотрено.

Тема от этого остаётся тонкой — 32 КБ на всё.

## Сборка

```bash
python3 build.py
```

| Что собирается | Куда класть на сервере |
|---|---|
| `theme/roschupka/` | `blog/system/themes/` |
| `site/gradient-generator/` | корень сайта |
| `extras/` | `blog/user/extras/` |

Эти три папки в репозитории не хранятся: они целиком выводятся из исходников.

⚠️ При обновлении Эгеи папка `system/` стирается, а `user/` остаётся. Тему после обновления движка надо ставить заново, расширения переживут.

## Что где лежит

```
assets/css/tokens.css    цвета, шрифты, кегли, отступы — единственный источник правды
assets/css/base.css      тема блога поверх plain
assets/css/gradient.css  страница генератора
assets/nav.html          меню: один источник для блога и статических страниц
assets/extras/           расширения Эгеи: шапка блога и подключение иконок
assets/root/             robots.txt и sitemap.xml
pages/                   статические страницы
references/spec.md       как размечать тексты заметок
references/decisions.md  почему сделано именно так: замеры, грабли, отменённые ходы
plan.md                  ход работ по этапам
```

## Локальная вёрстка

Тема пишется против настоящей разметки Эгеи: страница блога сохраняется как есть, а стили подменяются на свои. PHP для этого не нужен.

```bash
python3 serve.py   # http://localhost:4173
```

Снимки страниц лежат в `local/` и в репозиторий не входят. Чтобы сделать свои: сохраните страницу блога, удалите из неё `<base href>` и подключите `assets/css/` вместо родных стилей.

## Ограничения бесплатной версии

Встраиваемая тема, глобальные стили, плиточная лента и своё меню в Эгее платные. Обходятся так: своя тема плюс расширения в `user/extras/` — файлы с HTML, который движок вставляет в готовые слоты шаблона. Общее меню сайта и фавиконки по разделам сделаны ими.

## Редизайн 2026

Было: тема 2023 года на Literata и Open Sans, отдельная страница-заглушка на входе, генератор на сайте отсутствовал.

Стало:

- типографика на PT Serif и PT Sans, колонка 600 px под 63 знака в строке;
- общая шапка на всех страницах: рукописный вордмарк, меню, жёлтый мазок маркера на текущем разделе;
- генератор градиентов: цвет и пятно на холсте — одна сущность, точки перетаскиваются;
- корень сайта отдаёт блог, заглушка убрана;
- картинки блога пережаты со 161 до 96 МБ, robots.txt и sitemap переписаны.

Подробности и замеры — в [references/decisions.md](references/decisions.md).

Сайт до редизайна — тег [`v1-before-redesign`](https://github.com/gonz0tema/roschupka.ru/releases/tag/v1-before-redesign).
