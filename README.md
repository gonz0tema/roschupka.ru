# roschupka.ru 📝

Личный блог с портфолио на чистом HTML и CSS. Место, где я делюсь мыслями, проектами и идеями.

## Что здесь?

Сайт состоит из трех основных разделов:

- **Блог** — статьи, мысли и заметки
- **Портфолио** — мои проекты и работы
- **Главная** — стартовая страница (заглушка)

## Структура

```
├── index.html           # Главная страница
├── blog.html           # Раздел блога
├── portfolio.html      # Раздел портфолио
├── css/
│   ├── style.css       # Основные стили
│   ├── blog.css        # Стили для блога
│   └── portfolio.css   # Стили для портфолио
└── assets/             # Изображения, шрифты и т.д.
```

## Технологии

- 🏗️ **HTML5** — структура и семантика
- 🎨 **CSS3** — стили и оформление
- 📱 **Responsive Design** — адаптация под мобильные устройства

Никаких фреймворков, никакого JavaScript (пока) — чистый, легкий и быстрый код.
